# 📊 Student Performance Analyzer

## 📌 Project Description
A Python-based tool to analyze student performance data using **Pandas**.  
This project reads student data from a CSV file and generates useful insights like:
- Total students
- Average marks
- Highest and lowest marks
- Top 3 students
- City-wise performance report
- Export results to a new CSV

## 🚀 How to Run
1. Clone this repository  
   `git clone https://github.com/Ajwatahir9/student-performance-analyzer.git`
2. Install pandas  
   `pip install pandas`
3. Run the script  
   `python analyzer.py`
